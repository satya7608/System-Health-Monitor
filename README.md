# System Health Monitor

A Linux-based system health monitoring tool developed using Bash on RHEL 10.

## Features

- CPU usage monitoring
- Memory usage monitoring
- Disk usage monitoring
- Network information
- Process monitoring
- System uptime
- Load average
- Logged-in users
- Top CPU processes
- Top memory processes
- Failed login detection
- System temperature
- Battery status
- Health report generation

## Technologies

- RHEL 10
- Linux
- Bash Shell Scripting
- Git
- GitHub
