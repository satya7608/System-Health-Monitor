# System Health Monitor

A Linux-based system health monitoring and security automation tool built and tested on RHEL 10 using Bash scripting.

## Overview

System Health Monitor performs automated checks of important Linux system resources, services, networking, processes, security status, and system health. It generates detailed TXT and HTML reports for analysis.

## Features

- CPU usage monitoring
- Memory and SWAP monitoring
- Disk usage and critical disk alerts
- Network interface and IP information
- Network statistics and listening ports
- Running process monitoring
- Top CPU and memory consuming processes
- Logged-in users and login history
- System uptime and load average
- System temperature monitoring
- Battery status detection
- SSH security checks
- Failed login detection
- Firewall status check
- Suspicious process detection
- World-writable file checks
- Antivirus/ClamAV status check
- Running and failed services monitoring
- Overall system health score
- Automated TXT and HTML report generation
- Alert report generation
